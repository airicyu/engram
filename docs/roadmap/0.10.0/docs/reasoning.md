# 0.10.0 WHY

The four sections were always different kinds of understanding: who, relations, stable facts, and the present. Distill was told to update a node and not to copy the diary into it. It was not told to replace the two fact sections. A model that must not delete memory appends another "as of" block. Chain week and month files avoid that because the skill says to replace the whole file and to leave detail in the day.

A sweep of every node on each distill was rejected. That is a second pass over the vault, close to the consolidate loop this product does not run. Touching a node only when this run already updates it keeps one writing session and leaves quiet files alone until the next event names them.

A server diff that rejects appended snapshots was rejected. Whether a sentence is still the present is judgment. It stays in the skill.
